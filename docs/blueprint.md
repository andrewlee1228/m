# **App Name**: Axxel

## Core Features:

- Rent Payment: Allows 'Live' users (long-term residents) to pay rent directly through the app.
- Maintenance Requests: Enables users to submit and track maintenance requests, including descriptions and photo uploads.
- Community Events: Provides access to community events with RSVP options.
- Check-In/Out: Supports check-in via QR code or link, and checkout with feedback forms.
- AI Concierge: AI tool for suggesting local attractions and services.  

## Style Guidelines:

- Primary color: Deep teal (#008080) for a sense of stability and modernity.
- Secondary color: Light gray (#F0F0F0) to provide a clean and neutral backdrop.
- Accent: Coral (#FF7F50) to highlight important actions and elements.
- Clean and modern typography to ensure readability.
- Consistent use of line icons for a clean and modern aesthetic.
- Card-based design to present information in a clear and organized manner.
- Subtle transitions and animations to enhance user experience without being distracting.
